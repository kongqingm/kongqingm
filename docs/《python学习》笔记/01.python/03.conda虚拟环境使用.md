## 1、创建虚拟环境

```
conda create --name 虚拟环境名
```

## 2、激活虚拟环境

```
conda activate 虚拟环境名
```

## 3、查看虚拟环境列表

```
conda env list
```

## 4、删除虚拟环境

```
conda remove --name 环境名 
```
